# Поиск по фото

FastAPI + ChromaDB + чистый HTML/JS. Фото берутся из `../photo` (рядом с `photosearch/`).

```bash
pip install -r requirements.txt
python run.py            # http://127.0.0.1:8000
python -m pytest         # тесты
```

Переменные: `PHOTO_DIR`, `DATA_DIR`, `PORT`, `HOST`, `EMBEDDER=auto|clip|color`, `FACES=auto|dlib|off`.

- **clip** — семантический поиск («собака на пляже»), CLIP ViT-B/32 через fastembed; модель (~350 МБ) скачивается при первом запуске.
- **color** — офлайн-режим без моделей: ищет по названию цвета и по похожим фото.
- `auto` пробует CLIP и при неудаче переключается на color (в интерфейсе появится предупреждение).

Кнопка «Переиндексировать» работает инкрементально (новые/изменённые/удалённые файлы), прогресс виден в UI.
Тестовые картинки: `python scripts/make_samples.py ../photo` (только если папка пуста).

## Поиск человека по лицу

Находит **все фото в вашей папке**, где есть нужный человек — в том числе групповые.
Всё работает локально, фото никуда не отправляются.

**В веб-интерфейсе:** кнопка «👤 Найти человека» → выберите 1–5 фото этого человека.
- Если на фото несколько лиц, сверху появятся их миниатюры — нажмите на нужное.
- Ползунок «Строгость»: вправо — больше находок (и риск чужих), влево — только уверенные совпадения.
- На каждой находке в углу видно найденное лицо; кнопка «ещё» ищет уже по нему (удобно, чтобы добрать фото в другом ракурсе).

**Одной командой, без сервера:**
```bash
python find_face.py мама.jpg мама2.jpg --photos ~/Pictures --out ~/Найдено/мама
```
Скрипт проверит все фото (и во вложенных папках), напечатает список с процентом сходства, сохранит
`found_faces.csv` и с `--out` скопирует находки в отдельную папку (оригиналы не трогает).
Опции: `--tolerance 0.55` (строгость, 0.45 строго … 0.6 мягко), `--face N` — какое лицо взять с эталона.

Как устроено: dlib находит лица и превращает каждое в 128-мерный вектор (ResNet, ~99.4 % на LFW);
у одного человека векторы близки (расстояние < ~0.6). В веб-версии векторы всех лиц хранятся в ChromaDB,
поэтому поиск после индексации мгновенный. Модели (~100 МБ) ставятся с PyPI пакетом `face_recognition_models`;
если его установка падает на старом pip — `pip install --use-pep517 face_recognition_models`.

Ограничения: хуже находит лица в профиль, очень мелкие (меньше ~40 px), сильно размытые или закрытые;
у детей и близких родственников возможны ложные совпадения — снизьте строгость. Используйте для своих фото
и фото людей, которые не против: распознавание лиц без согласия во многих странах запрещено законом.
