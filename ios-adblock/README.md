# ZeroAds — блокировщик рекламы для iPhone

Честно о возможностях iOS: Apple не даёт сторонним «плагинам» перехватывать весь трафик телефона
так, как это делают блокировщики на компьютере. Поэтому ZeroAds состоит из **двух уровней**, которые
вместе убирают подавляющую часть рекламы:

| Уровень | Где работает | Что нужно |
|---|---|---|
| **1. DNS-профиль** `profiles/AdBlock-DNS.mobileconfig` | **Все приложения**, браузеры, Wi-Fi и LTE | Только iPhone, 1 минута |
| **2. Safari-расширение** (Xcode-проект) | Safari: блокирует запросы + скрывает пустые рекламные блоки | Mac с Xcode |

## 1. DNS-профиль — системная блокировка (рекомендуется начать с него)

Профиль включает зашифрованный DNS (DNS-over-HTTPS) через бесплатный AdGuard DNS. Запросы к рекламным
и трекинговым серверам просто не разрешаются — реклама не загружается ни в одном приложении.

1. Отправьте себе файл `profiles/AdBlock-DNS.mobileconfig` (AirDrop, почта, iCloud Drive) и откройте
   его **на iPhone** (из Файлов — через «Поделиться», или в Safari).
2. **Настройки → Профиль загружен → Установить**, введите код-пароль.
3. **Настройки → Основные → VPN и управление устройством → DNS** — убедитесь, что выбран «ZeroAds DNS».

Отключить: *Настройки → Основные → VPN и управление устройством → ZeroAds → Удалить профиль*.

> Хотите свои списки и статистику? Зарегистрируйтесь в AdGuard DNS / NextDNS, получите личный адрес
> DoH и замените `ServerURL` в профиле.

## 2. Safari-расширение (Content Blocker)

```bash
brew install xcodegen
cd ios-adblock
python3 tools/build_rules.py      # пересобрать правила (необязательно — готовый файл уже есть)
xcodegen                           # создаст ZeroAds.xcodeproj
open ZeroAds.xcodeproj
```

1. В `project.yml` замените `com.example` на свой идентификатор и укажите `DEVELOPMENT_TEAM`
   (или выберите команду в Xcode → Signing & Capabilities для обоих таргетов).
2. Подключите iPhone, выберите его в Xcode, нажмите **Run**. Подойдёт и бесплатный Apple ID
   (приложение надо будет переподписывать раз в 7 дней), с платным аккаунтом — на год.
3. На iPhone: **Настройки → Приложения → Safari → Расширения → ZeroAds → включить**.
4. Откройте ZeroAds — статус должен стать зелёным.

### Свои правила

- `rules/domains.txt` — домены (поддомены блокируются автоматически);
- `rules/selectors.txt` — CSS-селекторы рекламных блоков для скрытия;
- большой внешний список: `python3 tools/build_rules.py --hosts-url https://adaway.org/hosts.txt`
  (лимит Safari — 150 000 правил, скрипт обрежет лишнее).

После пересборки запустите приложение снова и нажмите «Обновить правила».

## Ограничения

- **YouTube / Instagram / TikTok** отдают рекламу с тех же серверов, что и сам контент — DNS их не
  отличит. Для YouTube помогает просмотр в Safari с включённым расширением.
- Если какое-то приложение или сайт сломался — временно отключите профиль и проверьте, затем
  уберите лишний домен из своего списка.
- Безопасность: профиль подписан не будет («Не проверен») — это нормально для самодельных профилей;
  он лишь меняет DNS-сервер и ничего не читает с телефона.
