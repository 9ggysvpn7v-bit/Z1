# Платный Telegram-бот (оплата Telegram Stars)

Бот продаёт доступ на N дней за Stars. Цена и срок показываются до оплаты, доступ выдаётся сразу,
есть `/terms`, `/paysupport`, `/support`, `/status`, `/delete` и возврат владельцем `/refund <user_id> <charge_id>`.

## Запуск
1. Создайте бота в @BotFather, получите токен. Свой user id узнайте у @userinfobot.
2. `pip install -r requirements.txt`
3. `export BOT_TOKEN=... ADMIN_ID=... PRICE_STARS=100 ACCESS_DAYS=30 SUPPORT_CONTACT=@вы`
4. Замените тексты в `TEXTS` и функцию `deliver()` в `bot.py` на ваш продукт (ссылка, файл, закрытый канал).
5. `python bot.py`; проверьте оплату на минимальной сумме.

## Как получить деньги
Stars копятся на балансе бота. Вывод делает владелец через официальный Fragment (в TON, обычно с выдержкой
~21 день и минимальным порогом; уточняйте актуальные условия), затем TON -> валюта через обменник/биржу.
Доход нужно учитывать по законам вашей страны; посоветуйтесь с бухгалтером.

## Честность
Не обещайте доход, не накручивайте отзывы, не рассылайте спам, помечайте рекламу. Возвращайте Stars,
если товар не доставлен. Доход зависит от ценности продукта и вашей аудитории, гарантий нет.
